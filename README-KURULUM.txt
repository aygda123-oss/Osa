# OSA Şube Denetim Asistanı — GitHub Pages

Bu klasörde yayın için gereken dosyalar bulunur:

- `index.html` — uygulama
- `manifest.webmanifest` — ana ekrana ekleme bilgileri
- `sw.js` — çevrimdışı önbellek
- `icon.svg` — uygulama simgesi
- `apple-touch-icon.png` — iPhone ana ekran simgesi

## GitHub'a yükleme

Bu ZIP'i bilgisayarda/telefonun Dosyalar uygulamasında açın ve içindeki beş dosyayı
`aygda123-oss/Osa` deposunun `main` dalındaki kök dizine yükleyin.
Mevcut `index.html` varsa üzerine yazın.

Ardından GitHub → Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save.

Yayın adresi:
https://aygda123-oss.github.io/Osa/

Yayınlandıktan sonra iPhone'da Safari ile açıp Paylaş → Ana Ekrana Ekle seçin.
Çevrimdışı önbelleğin ilk kurulum için uygulama en az bir kez internet bağlantısıyla açılmalıdır.
